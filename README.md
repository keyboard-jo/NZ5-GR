# NZ5 Generative Recommendation System
## Introduction
This is an ongoing project. This repository holds scripts and notebooks for the NZ5 Independent Project. The project involves trianing an RQ-VAE model for the [TencentGR-1M](https://huggingface.co/datasets/TAAC2025/TencentGR-1M) dataset and benchmarking various methods to use semantic ID for recommender systems.
